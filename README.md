# Machine Learning Practicals

## Overview

This repository contains selected machine learning practicals completed using Python and scikit-learn.

The notebooks demonstrate hands-on work with data preprocessing, classification, model evaluation and cross-validation.

## Included Projects

### Data Preprocessing
- Data loading and preparation
- Train / validation / test splitting
- Pandas and NumPy
- Basic data transformation

### Classification
- K-Nearest Neighbours (KNN)
- Naive Bayes
- Cross-validation
- GridSearchCV
- Accuracy evaluation

## Tech Stack

- Python
- Jupyter Notebook
- Pandas
- NumPy
- scikit-learn
- Matplotlib
